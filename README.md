# Telegram-бот: ежедневный отчёт Ozon + Wildberries

Простой MVP для одного собственника.

## Что делает бот

Каждый день в `REPORT_TIME` бот берёт данные за предыдущий календарный день, сохраняет результат в SQLite и отправляет одно сообщение в Telegram.

Доступна команда `/report` — она возвращает последний сохранённый отчёт. Если отчётов ещё нет, команда получает данные за вчера и сохраняет их.

## Какие поля используются

### Ozon

1. `POST /v1/analytics/data`
   - `ordered_units` → количество проданных/заказанных единиц;
   - `revenue` → сумма заказов.

2. Для количества заказов отдельно используются текущие методы списка отправлений:
   - FBS: `/v4/posting/fbs/list`;
   - FBO: `/v3/posting/fbo/list`.

   Для отчётного дня считается количество уникальных `order_id` (с запасным вариантом `posting_number`) среди отправлений со статусами, которые не являются отменёнными.

### Wildberries

`GET /api/v1/supplier/sales?dateFrom=YYYY-MM-DD&flag=1`

- одна строка = одна продажа/возврат = одна единица товара;
- `saleID` с префиксом `S` → продажа;
- `saleID` с префиксом `R` → возврат;
- `srid` → идентификатор заказа;
- `finishedPrice` → фактическая цена заказа с учётом скидок; используется как сумма продажи.

В отчёте продажи и возвраты учитываются нетто: возврат уменьшает количество и сумму. Заказы — это количество уникальных `srid` среди продаж `S*`.

## Важное ограничение Wildberries

Метод `/api/v1/supplier/sales` — оперативный предварительный отчёт. Документация WB указывает, что ценовые поля могут временно быть `0` и обновляться до 24 часов. Поэтому бот не считает такой ответ корректным: если среди строк отчёта есть строки с нулевым `finishedPrice`, блок Wildberries помечается ошибкой, а общий итог не рассчитывается.

## Установка

```bash
python -m venv .venv
```

Linux/macOS:

```bash
source .venv/bin/activate
```

Windows:

```powershell
.venv\Scripts\activate
```

```bash
pip install -r requirements.txt
cp .env.example .env
```

Заполнить `.env`, затем:

```bash
python tg_bot.py
```

## Тесты

```bash
python test_bot.py
```

Скрипт прогоняет юнит-тесты форматирования отчёта и логики Wildberries,
а затем интеграционный тест `ozon_sales`/`wb_sales` на замоканных HTTP-ответах
(реальные запросы в сеть не уходят). При успехе выводит `ALL TESTS PASSED`
и `API MOCK TESTS PASSED`.

## Безопасность

`.env` содержит реальные токены и никогда не должен попадать в git —
он уже добавлен в `.gitignore`. `.env.example` — это только шаблон с
плейсхолдерами; если в него случайно попадёт настоящий токен, он
считается скомпрометированным, и его нужно немедленно отозвать
(для Telegram-токена — командой `/revoke` у @BotFather) и выпустить новый.

## Защита от повторной отправки

В SQLite хранится одна запись на календарную дату. В ней фиксируются:

- показатели Ozon;
- показатели Wildberries;
- признаки успешного получения каждой площадки;
- текст ошибки, если площадка недоступна;
- время получения данных;
- `sent_at` — факт успешной отправки сообщения.

При перезапуске приложения уже отправленная дата повторно не отправляется.
