# Обновление до 1.0.14

1. В боте нажмите **Ещё → Техническое → Создать backup** и сохраните файл.
2. Выполните **ребилд из ветки main** на BotHost. Используйте прежние ключи, `DB_FILE` и постоянный диск.
3. Откройте **Проблемы → Активные проблемы** или **Что делать сегодня**. На странице будет не больше пяти пунктов. Стрелки меняют страницу, **Подробнее** открывает расчёт, **К списку** возвращает назад.
4. В товарных отчётах нажмите **📋 WB / Ozon / Внутренний**: скопируется только артикул. Для штатного копирования нужен клиент Telegram, поддерживающий CopyTextButton.
5. В **Поставки → Обновить акции** запустите одну загрузку. Завершённые акции WB больше не вызывают запросы товаров. Если действующая акция вернёт ошибку, бот покажет её номер и ответ API. Старые записи ошибок в истории остаются; новое обновление показывает текущий результат.

Рабочие даты и время отображаются как **03.10.2026 09:09** по часовому поясу магазина. Периоды и расчёты не меняются. Версия репозитория — **1.0.14**, схема БД — **18**.

Новые роли сотрудников отложены до отдельного согласования. Для рекламы Ozon по-прежнему нужны отдельные ключи Ozon Performance; этот релиз не создаёт их автоматически.
