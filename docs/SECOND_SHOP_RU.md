# Как подключить ещё один магазин

Версия 1.0.13 · 03.10.2026

Один Telegram-бот может работать с несколькими магазинами. Каждый магазин имеет свои ключи, отчёты, настройки и сотрудников. Новый Telegram-бот для второго магазина не нужен.

## 1. Получите ключи второго кабинета

Зайдите именно в кабинет **второго** магазина.

- **WB:** откройте раздел интеграций по API и создайте токен с нужными категориями. Бот читает данные: Статистика, Аналитика, Финансы, Продвижение, Поставки, Цены и скидки. Тип токена выбирайте по правилам WB для вашего способа размещения программы. Новые финансовые методы могут быть недоступны базовому токену.
- **Ozon:** в настройках подключения Seller API получите **Client ID** и **API Key** одного кабинета. Ключ должен разрешать чтение аналитики, финансов, товаров, остатков и поставок, которыми вы пользуетесь. Названия ролей уточняйте в текущем кабинете.
- **Реклама Ozon:** отдельно получите **Client ID** и **Client Secret** для **Ozon Performance**. Пара Seller API не заменяет эту пару. Без Performance обычные отчёты Ozon работают, но рекламная статистика не загружается.

Инструкции площадок: [типы токенов WB](https://dev.wildberries.ru/knowledge-base/articles/019d49a0-f60a-7b42-bcbb-15b1cfee9023/sposoby-podkliucheniia-k-wb-api-token-i-oauth-2-0), [Seller API Ozon](https://docs.ozon.ru/api/seller/), [Performance API Ozon](https://docs.ozon.ru/api/performance/). WB предназначает персональный токен для собственных программ на своей инфраструктуре и запрещает передавать его сторонним облачным сервисам; сервисный токен связан с сервисом из каталога WB.

## 2. Сохраните ключи на BotHost

Откройте настройки **уже работающего приложения** → переменные окружения. Название этого раздела зависит от интерфейса BotHost. Создайте отдельную группу ключей с именем **SHOP2**. В каждом поле имя и значение задаются отдельно, без кавычек:

| Имя переменной | Что вставить в значение |
| --- | --- |
| `SELLERBOT_SHOP2_WB_API_TOKEN` | Токен WB второго магазина |
| `SELLERBOT_SHOP2_OZON_CLIENT_ID` | Client ID Seller API второго магазина |
| `SELLERBOT_SHOP2_OZON_API_KEY` | API Key Seller API второго магазина |
| `SELLERBOT_SHOP2_OZON_PERF_CLIENT_ID` | Client ID Performance второго магазина, если нужна реклама |
| `SELLERBOT_SHOP2_OZON_PERF_CLIENT_SECRET` | Client Secret Performance второго магазина, если нужна реклама |

Если подключаете только WB, достаточно первой строки. Для Ozon нужны обе строки Seller API. Для рекламы Ozon нужны обе строки Performance.

**Ключи первого магазина оставьте в прежних переменных.** `DEFAULT` использует обычные `WB_API_TOKEN`, `OZON_CLIENT_ID`, `OZON_API_KEY` и `OZON_PERF_*`. `SHOP2` — название группы настроек, а не токен и не номер магазина.

Сохраните изменения и **перезапустите приложение**, чтобы бот прочитал новые значения. Если BotHost применяет переменные только при пересборке, сделайте ребилд. Сам код ради нового магазина менять не нужно. Сохраните прежние `DB_FILE` и постоянный диск с базой.

Токены не отправляйте сообщением в Telegram и не добавляйте в репозиторий. В базе сохраняется имя группы, а секреты читаются из окружения хостинга.

## 3. Создайте магазин в боте

Добавлять магазины может владелец установки: его Telegram ID указан в `TELEGRAM_OWNER_ID`.

1. Откройте **Магазин → Профили окружения → Открыть**. В списке должно появиться `SHOP2`.
2. Откройте **Магазин → Добавить магазин → Открыть**.
3. Отправьте одну строку: `Второй магазин | SHOP2`.
4. Бот создаст магазин и выберет его. Проверьте название и подключённые площадки в ответе.

Можно выполнить то же одной командой: `/shop_add Второй магазин | SHOP2`.

Если магазин уже создан, **не создавайте его повторно**: выберите его через **Магазин → Выбрать магазин**, затем **Профиль ключей → Открыть** и отправьте `SHOP2`. Команда для этого: `/shop_profile SHOP2`.

## 4. Настройте и загрузите данные

1. **Магазин → Мастер настройки → Открыть.** Укажите название, часовой пояс, время отчёта и пороги предупреждений. Для Кировской области подходит `Europe/Kirov`.
2. **Магазин → Проверить API → Открыть.** Проверьте доступ к WB/Ozon. Реклама Ozon проверяется отдельно.
3. **Отчёты → Догрузить данные → Открыть.** Выберите площадку и сначала 30 дней для истории спроса. Загрузите обе площадки, если подключены обе.
4. **Деньги и реклама → Обновить все отчёты → Открыть.** Выберите **Вчера**, **7 дней** или нужные даты, затем **Обновить**. Дождитесь результата.
5. **Товары → Импорт себестоимости → Открыть.** Загрузите цены за одну штуку. Для старых отчётов укажите дату начала действия цены.
6. **Товары → Обновить остатки → Открыть**, затем **Поставки → Обновить поставки в пути → Открыть**.
7. **Поставки → Обновить план → Открыть.** Проверьте сроки доставки и упаковки перед закупкой.
8. Посмотрите **Полноту источников**, **Начисления Ozon/WB** и **Активные проблемы**.

Кнопка **Подробнее** объясняет действие, **Свернуть** скрывает пояснение в том же сообщении. **Открыть** запускает функцию. Для обновления периода требуется дополнительная кнопка **Обновить**.

## 5. Переключение и сотрудники

- **Магазин → Выбрать магазин → Открыть:** выберите нужный магазин кнопкой. Выбор действует лично для вас; у другого сотрудника может быть выбран другой магазин.
- Перед обновлением сверяйте имя магазина в главном меню. Кнопки выбора периода старого магазина не обновят новый.
- Для доступа сотрудника выберите магазин и выполните `/user_add TELEGRAM_ID viewer Имя`. `viewer` читает отчёты, `analyst` также обновляет данные, `owner` управляет настройками и доступом магазина.
- Telegram ID — числовой ID человека, не `@username` и не ID бота. Для другого магазина доступ выдаётся отдельно.
- Третий магазин подключается так же: новые переменные `SELLERBOT_SHOP3_...` и группа `SHOP3`.

## Если подключение не получилось

| Что видно | Что проверить |
| --- | --- |
| Нет кнопки добавления магазина | Ваш ID должен быть в `TELEGRAM_OWNER_ID`; после изменения нужен перезапуск |
| В профилях нет `SHOP2` | Точное написание переменных и перезапуск приложения |
| Ozon отсутствует в списке подключений | Обе переменные Seller API заполнены: Client ID и API Key |
| Рекламы Ozon нет | Отдельная пара Performance, «Проверить API», затем «Обновить рекламу» |
| Ошибка 401/403 | Ключ, срок действия, кабинет и категории/роли доступа; после замены ключа перезапуск |
| Отчёт пустой | Нужный магазин, загруженные даты и статус источников; отсутствие данных не означает ноль |
| Цифры похожи на первый магазин | Не назначен ли второму магазину `DEFAULT` или ключи первого кабинета |

**Замена ключа позже:** измените значение соответствующей переменной `SELLERBOT_SHOP2_...`, перезапустите приложение и проверьте API. Если имя группы остаётся `SHOP2`, заново создавать магазин или менять его профиль не нужно.
