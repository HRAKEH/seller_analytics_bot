# Обновление до 1.0.9: цены покупателей и автоматический курс ЦБ

Ежедневный отчёт Ozon теперь показывает три отдельные суммы: заказы по предельной цене, заказы по цене покупателя и начисления после удержаний. Цена покупателя хранится в исходной валюте. При валютных заказах бот автоматически запрашивает курс ЦБ для даты отчёта и добавляет рублёвую оценку.

## Как обновить

1. Создайте `/backup` и сохраните файл.
2. Обновите `main` и выполните rebuild на Bothost, сохранив каталог БД и переменные окружения.
3. Проверьте `/diagnostics`: актуальная схема — **16**. Релиз **1.0.9** указан в `VERSION`. При запуске существующая БД мигрирует автоматически; перед миграцией также создаётся локальный backup.
4. Обновите нужный день: `/refresh 1 YYYY-MM-DD`. Дождитесь итогового сообщения, включая этап отправлений FBO/FBS.
5. Откройте «📊 Отчёты» → «🗓 Другая дата» и выберите тот же день. Если в заказах есть иностранная валюта, курс ЦБ загрузится автоматически при формировании отчёта. Отдельный токен или платная подписка для ЦБ не нужны.
6. Для сохранения проверки создайте новый `/backup`: в него входят и цены отправлений, и использованный XML ЦБ.

Обычный ежедневный цикл сам собирает цены через этап сверки отправлений и получает необходимый курс перед отправкой сообщения. Команда `/day YYYY-MM-DD` также обновляет заказы и цены. Просмотр сохранённого дня использует БД для заказов и цен; при отсутствии курса делает только запрос в ЦБ.

## Как читать результат

Пример с условными суммами:

```text
по цене покупателя: 1 000.00 ₽ + 10.00 BYN
оценка в рублях по ЦБ: ≈ 1 250.00 ₽
курс ЦБ: 1 BYN = 25 ₽ · действует с 2026-10-01, для 2026-10-01
```

Первая строка содержит исходные цены Ozon. Вторая — оценку: рублёвые цены плюс валютные цены, умноженные на официальный курс. Курс для валют с номиналом 10, 100 и т.д. делится на этот номинал. Арифметика использует Decimal, итог округляется один раз до копеек.

Бот запрашивает курс на дату отчёта, а не на день его просмотра. В выходные XML может содержать курс, действующий с более ранней даты: обе даты показаны в сообщении. Исторический XML повторно используется из БД; для текущего дня сохранённый курс может обновиться спустя час. Сбой повторного запроса не удаляет корректный сохранённый курс для той же даты.

Пересчёт ЦБ обозначен как оценка. Метод пересчёта иностранной цены в рубли в аналитике Ozon пока не подтверждён, поэтому точное совпадение с кабинетом не обещается. Начисления после удержаний относятся к дате начисления и могут включать заказы других дней.

## Неполные данные

- До получения всех цен показывается сумма **по полученным ценам покупателя, неполно**, число единиц с ценой и число заказов из аналитики.
- Для полноты должны совпасть SKU и количества в отправлениях и аналитике. Одинаковое общее количество при разных SKU не считается полной сверкой.
- Цена FBO берётся только из деталей, связанных с текущим снимком списка. Отмена заказа сама по себе не исключает его из показателя заказов. Настоящая нулевая цена учитывается, отсутствующая цена или валюта — нет.
- Если ЦБ недоступен или не содержит нужную валюту, исходные суммы в валютах остаются видны, а полный рублёвый итог скрыт.
- При изменении состава заказов обновите все отчёты за тот же день и повторите просмотр.
