# Проверка остатков и оповещений

Низкий запас в днях — прогноз: полученный остаток делится на среднее число заказанных единиц за загруженные дни. Изменение истории заказов может изменить прогноз без пополнения склада.

FBW/FBO — склад площадки. FBS — склад продавца. Положительный остаток на одной ранее используемой схеме не означает, что товар есть на другой.

Если ранее использовавшаяся схема исчезла из текущего отчёта, её остаток не подтверждён. Отсутствующая строка не приравнивается к нулю. При ошибке или неполных данных прежнее предупреждение не снимается. В сводке и активных проблемах показаны полученные количества по схемам и причина проверки.

«Предупреждение по запасу снято» означает, что подтверждённые остатки и рассчитанный прогноз больше не удовлетворяют условию предупреждения. Это сообщение не подтверждает факт пополнения. «Данные об остатке получены» относится к доступности данных; даже при нулевом остатке отдельно остаётся критичная проблема.

После ребилда откройте «Остатки и запас» и нажмите «Обновить остатки». Сверяйте ту же площадку, артикул и схему со складом в кабинете. Технические переменные и файл действующей БД остаются прежними. Старые сообщения в Telegram не изменяются автоматически.

Исходные успешные ответы WB по остаткам теперь сохраняются. Для старых загрузок, где их нет в бэкапе, установить причину отсутствия строки по ответу API невозможно.
