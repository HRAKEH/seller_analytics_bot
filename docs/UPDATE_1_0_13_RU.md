# Обновление до 1.0.13

1. Сделайте резервную копию базы: **Ещё → Техническое → Создать бэкап → Открыть** или `/backup`.
2. Выполните **ребилд из обновлённого репозитория** на BotHost. Оставьте прежний `DB_FILE`, постоянный диск и ключи. Версия меняется на **1.0.13**, схема остаётся **18**.
3. После запуска отправьте `/start` и проверьте выбранный магазин. Если под полем ввода осталась старая клавиатура, используйте новое меню в сообщении бота.
4. **Магазин → Проверить API → Открыть**. Для рекламы Ozon нужны отдельные `OZON_PERF_CLIENT_ID` и `OZON_PERF_CLIENT_SECRET`; для `SHOP2` — `SELLERBOT_SHOP2_OZON_PERF_CLIENT_ID` и `SELLERBOT_SHOP2_OZON_PERF_CLIENT_SECRET`. После добавления этих ключей перезапустите приложение.
5. **Товары → Обновить остатки → Открыть**, затем **Поставки → Обновить поставки в пути → Открыть**. Дождитесь результатов, проверьте площадки, количество и время снимков. Новая FBO-загрузка Ozon использует известные SKU: если история ещё не загружена, сначала **Догрузить данные**.
6. **Деньги и реклама → Обновить все отчёты → Открыть → Вчера → Обновить**. Для проверки другой даты выберите её в календаре. Обновлять можно до 31 завершённого дня за один запуск.
7. Откройте **Полноту источников**, **Начисления WB/Ozon**, **Остатки**, **Экономику по товарам** и **Активные проблемы**. Ошибка отдельного источника отображается явно; предыдущие успешные данные сохраняются.
8. Заполните себестоимость, если она отсутствует. Затем **Поставки → Обновить план → Открыть**. До закупки проверьте срок доставки, страховой запас и упаковку.

## Как работает новое меню

- Выберите раздел, затем функцию.
- **Подробнее** показывает объяснение, **Свернуть** скрывает его в этом же сообщении.
- **Открыть** запускает функцию либо показывает выбор периода.
- **Вчера**, **7/14/30 дней** и календарь заменяют ввод дат текстом. Перед запросами в API отдельно нажимается **Обновить**; сохранённые отчёты открываются кнопкой **Показать**.
- Старая кнопка периода после нового выбора, смены магазина или отзыва прав не запускает обновление.

## Что означают остатки

**3 шт.** — количество товара. **14 дней** — запас при среднем спросе примерно 0,214 шт./день. Это разные величины. В активных проблемах теперь видны обе, вместе с названием, площадкой, артикулом и временем снимка.

Топ и экономика показывают WB/Ozon отдельно. Без полной себестоимости полный результат по товару не рассчитывается. Начисления WB — итоги финансовых отчётов с настоящими периодами, а не сумма новых заказов и не подтверждение денег в банке.

## Второй магазин

Откройте [инструкцию по добавлению магазинов и токенов](SECOND_SHOP_RU.md). Ключи второго кабинета задаются отдельной группой `SHOP2`; существующие ключи первого кабинета остаются на месте.

Проверки релиза выполнены локально. Успешную загрузку новых методов Ozon на вашем действующем кабинете подтвердят результаты шагов 4–7 после ребилда.
