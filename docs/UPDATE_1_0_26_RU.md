# Обновление до 1.0.26

- Любой пользователь с ролью **Владелец** может архивировать, вернуть или удалить любой магазин этого бота. Создатель и внутренний seller_id больше не ограничивают эти действия.
- Бот оставляет минимум **один активный магазин**. Полное удаление доступно после архивации и подтверждения.
- Удалённый магазин не создаётся заново после перезапуска или изменения порядка TELEGRAM_OWNER_ID.
- Архив и кнопки управления видны всем владельцам. Бухгалтеру и менеджеру эти действия закрыты. Отчёты и управление сотрудниками продолжают проверять доступ к конкретному магазину.

Обновите код из Git и сделайте ребилд с прежними переменными, DB_FILE и каталогом данных. Откройте главное меню заново. Схема БД остаётся **21**; перенос базы и новые переменные не нужны. В тарифных сборках управление несколькими магазинами входит в **Business**.

Для лишнего магазина №2: **Магазин → Архивировать магазин → №2 → подтвердить**, затем **Магазин → Удалить магазин → №2 → подтвердить**. Архивация сохраняет историю; удаление стирает данные только выбранного магазина.
