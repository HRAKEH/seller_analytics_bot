# Отмены Яндекс Маркета по дате события

- Дневная карточка сохраняет показатель заказов без отмен и отдельно показывает отменённые единицы среди заказов выбранного дня.
- Уведомления ORDER_CANCELLED содержат cancelledAt, campaignId, orderId и состав заказа. Повтор одного заказа не увеличивает итог; различающиеся версии исключаются.
- Проверка через POST /v1/businesses/{businessId}/orders с orderIds и fake=false выполняется в фоне после сохранения события. Считаются только реальные полностью отменённые заказы с подтверждённым составом. Частичные отмены без подтверждённой даты не подставляются. Сумма отмен не подтверждается.
- Отчёт показывает нижнюю границу ≥ N, а не полный итог или ноль. Прошлые/пропущенные уведомления не восстанавливаются. Один HTTPS-адрес принимает все campaignId, однозначно сопоставленные текущим профилям.
- Используется общий HTTP-сервер с Ozon, миграция 25.

## Настройка

Включите HTTPS-домен Bothost. Создайте отдельный случайный URL-safe секрет (например, Python: python -c "import secrets; print(secrets.token_urlsafe(32))"). Укажите его в YANDEX_PUSH_SECRET на хостинге, не в GitHub. Пересоберите бота. В Маркете: Настройки → API и модули → API-уведомления → Подключить уведомления → для кабинета → только «Отмена заказа». URL: https://ВАШ-ДОМЕН/yandex/push/ВАШ-СЕКРЕТ/notification. Если интерфейс дописывает /notification автоматически, проверьте итоговый путь. Не передавайте секрет клиентам и не публикуйте адрес.

Защита: случайный секрет URL, проверка принадлежности campaignId текущему профилю и подтверждение заказа API. Проверка IP отправителя за reverse proxy Bothost не реализована, поскольку доверенный адрес прокси не подтверждён; не доверяйте произвольному X-Forwarded-For. Для строгой проверки настройте фильтр официальных IP Маркета на доверенном ingress. В HTTP access log приложения URL не записываются. Секрет не сохраняется в БД.

Официальные источники: https://yandex.ru/dev/market/partner-api/doc/ru/push-notifications/ и https://yandex.ru/dev/market/partner-api/doc/ru/push-notifications/reference/sendNotification.
