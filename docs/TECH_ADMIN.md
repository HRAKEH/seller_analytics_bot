# Техническое меню SellerBot

Техническая роль не выдаётся через «Сотрудники» и не зависит от тарифа. 
В Bothost укажите `TELEGRAM_OWNER_ID` с основным владельцем бота и клиентом-владельцем (ID через запятую).
В отдельной переменной `TECH_ADMIN_IDS` укажите только Telegram ID технического специалиста. 
ID должен одновременно присутствовать в `TELEGRAM_OWNER_ID`. 
Если `TECH_ADMIN_IDS` не заполнена, ни у кого нет доступа к /tech: безопасное поведение по умолчанию.

После перезапуска у указанного техадминистратора появится команда /tech в Telegram.
Команда работает только в личном диалоге с ботом, чужим ID бот на неё не отвечает.
Техраздел также доступен через «Ещё → Техническое» только техадминистратору.

Для владельца клиента сохранены управление магазинами и сотрудниками, рабочие настройки, отчёты, экспорт и проверка API. 
Вся инсталляция может содержать несколько магазинов, поэтому копии базы, восстановление, служебные ошибки и конфигурация Ozon Push доступны только техадминистратору.
Ни Telegram ID, ни роль «Владелец» в магазине сами по себе не дают техдоступ.
Токены маркетплейсов продолжают храниться в переменных окружения: через Telegram они не отображаются и не меняются.

Доступ проверяется повторно для команд, меню, старых callback-кнопок, повторов и страниц технических отчётов.
Для сотрудника сохраняются все прежние разрешённые разделы его тарифа и роли.

Автоматическая отправка полной резервной копии в Telegram при AUTO_BACKUP_SEND_TELEGRAM=true выполняется только на ID из TECH_ADMIN_IDS, включённые также в TELEGRAM_OWNER_ID. Клиент-владелец получает свои обычные отчёты и предупреждения, но не полный архив установки.
