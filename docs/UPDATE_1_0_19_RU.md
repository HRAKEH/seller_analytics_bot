# Обновление до 1.0.19

1. Сделайте резервную копию: **Ещё → Техническое → Создать backup**.
2. В BotHost выполните ребилд из ветки **main**. После запуска должны быть версия **1.0.19** и схема **21**. Базу и переменные хостинга сохраните; токены менять не нужно. Перед миграцией бот автоматически создаёт ещё одну копию базы.
3. Откройте новые карточки начислений и новый раздел скачивания. Старые сообщения сами не переписываются; старый выбор экспорта предложит открыть раздел заново.

## Начисления Ozon и WB

**Деньги и реклама → Начисления Ozon / Начисления WB → Открыть → выбрать период → Показать.**

| Кнопка | Что произойдёт |
| --- | --- |
| Подробнее | Откроется расшифровка в том же сообщении |
| ◀️ / ▶️ | Перелистнётся длинный список |
| Свернуть | Вернётся короткая сводка |
| Скачать CSV | Пришлёт таблицу с исходными кодами полей |
| Excel (.xlsx) | Пришлёт удобную таблицу с листами «Итог», «Операции Ozon» / «Отчёты WB» и «Описание полей» |

Файл больше не приходит автоматически. CSV и Excel берут те же сохранённые ответы, что открытая карточка. Если после обновления финансов площадка исправила цифры, откройте **новую** карточку — старая сохраняет прежнюю версию для сверки. Если исходные данные удалены, бот предложит открыть отчёт заново.

У WB **даты сохранения** показывают, за какие дни бот нашёл отчёты в базе. **Период самого отчёта WB** показывает, к каким продажам относится его сумма. Сумма недельного отчёта целиком относится к этой неделе. Если период один, он указан и в имени файла; если периодов несколько — имя файла обозначает даты сохранения. Неизвестные поля не заменяются нулём, предупреждения видны и в короткой сводке.

## Скачать данные магазина

**Ещё → Скачать данные магазина → Открыть → 7/30/90 дней.** Затем:

| Кнопка | Для чего |
| --- | --- |
| Скачать Excel (.xlsx) | Один файл с русскими листами, фильтрами и закреплёнными заголовками |
| Скачать архив CSV (.zip) | Отдельные таблицы с прежними кодами колонок и файлами пояснений |
| Что будет в файле | Посмотреть состав выгрузки; длинный список перелистывается |
| Другой период | Выбрать 7, 30 или 90 дней |
| Главное меню | Убрать выбор формата; скачанные файлы останутся |

Для свежих цифр сначала обновите отчёты. Остатки, поставки в пути и акции отражают сохранённое текущее состояние, а не историю всех изменений за выбранный период. Для восстановления бота нужна резервная копия базы, выгрузка её не заменяет.

Права прежние: владелец и бухгалтер видят финансы, менеджер — разрешённые рабочие данные. Смена выбранного магазина не меняет магазин уже открытой карточки. После отзыва прав или архивирования магазина скачивание закрывается. Кнопки новых карточек работают после перезапуска.

После ребилда проверьте одну карточку Ozon и одну WB: откройте подробности, скачайте оба формата и сравните итоги. Затем скачайте данные магазина и проверьте листы «Себестоимость», «Остатки» и «Описание полей» с учётом вашей роли.

Локальная проверка выпуска: **651 тест прошёл**, аудит релиза, preflight на отдельной базе, компиляция и зависимости успешны. Для тестов использован двойник Telegram; реальные сообщения и запросы маркетплейсам не отправлялись.
