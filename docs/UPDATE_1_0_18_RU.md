# Обновление до 1.0.18

1. Сделайте резервную копию через **Ещё → Техническое → Создать backup**.
2. В BotHost сделайте ребилд из ветки **main**. В логах должна быть версия **1.0.18**, схема **20**. Токены и путь базы менять не нужно; при переходе с 1.0.17 миграции нет.
3. Откройте новый отчёт через **Отчёты → Вчера** или выбор даты. Старые сообщения сами не переписываются.

Пример строки:

**Всего заказано: 159 шт. · ≈ 104 580,53 ₽**

Итог складывает суммы, показанные ниже по площадкам: **WB до удержаний + Ozon по цене покупателя в рублях**. Предельная цена Ozon и суммы после удержаний в этот итог не подставляются. При пересчёте BYN или другой валюты по ЦБ показан знак **≈**. Округление соответствует суммам строк площадок.

Если количество известно, но цены или курс неполные, бот показывает количество и надпись **«сумма неполная»**. Если данные по подключённой площадке отсутствуют, общий итог не выдаётся как полный. Настоящий ноль показывается как **0,00 ₽**.

Все изменения ролей из 1.0.17 включены в этот выпуск. Назначение сотрудников: **Магазин → Сотрудники → Открыть**. Подробности: [инструкция по ролям](UPDATE_1_0_17_RU.md).

Проверено локально: **635 тестов**, аудит релиза, зависимости, компиляция и preflight. После ребилда проверьте итог в новом отчёте за выбранный день.
