# Обновление 1.0.28

- Приём Push уведомлений Ozon об отменах FBO и FBS/rFBS, доступный во всех уровнях. HTTP работает в том же процессе, читает порт БотХоста и отдаёт /health и /ready.
- В техническом меню владелец создаёт отдельный защищённый адрес для магазина. Секрет выдаётся в личном чате, в БД хранится только хеш. Замена требует подтверждения и отключает старый адрес; прежние отмены сохраняются.
- Исходные JSON сохраняются в БД. Штуки — сумма products.quantity; день — cancel_date для FBO или changed_state_date для FBS, по Москве. TYPE_ORDER_CANCELLED без состава товаров не добавляет штуки.
- Повторы не удваивают итог. Конфликтующие версии исключаются и сохраняются для проверки. Seller ID отправителя закрепляется первым корректным событием. Другой отправитель отклоняется; смена кабинета требует нового адреса. Старые адреса не обходят ограничения уровня на магазины.
- Дневной отчёт показывает подтверждённую часть «≥ N шт. · по уведомлениям». Отсутствие уведомлений не считается нулём. Исторические и пропущенные события автоматически не восстанавливаются; сумма отмен не выводится из цены заказа.
- Схема 22. Обновление проверено на копии настоящего бэкапа: прежние записи и целостность сохранены. Инструкция: docs/OZON_PUSH_RU.md.

Порядок настройки: [Отмены Ozon](OZON_PUSH_RU.md).
