# Обновление до 1.0.21

1. **Ещё → Техническое → Создать backup**: сохраните резервную копию.
2. В BotHost выполните ребилд ветки **main**. После запуска проверьте версию **1.0.21**, схема базы **21**. Сохраните базу и переменные хостинга; токены для этого обновления менять не нужно.
3. Откройте **Отчёты → Вчера → Обновить**, затем **Подробнее**.

## Что исправлено

- При сбое загрузки продаж/возвратов WB за несколько дней ошибка теперь записывается для каждого запрошенного дня. Раньше HTTP-ошибка отмечалась только у первого дня, и остальные могли выглядеть успешно обновлёнными.
- Если выкупы, возвраты или отмены показываются из прежнего снимка после сбоя, рядом с цифрами видно **⚠️ сохранённые данные**. Это относится к ежедневной карточке WB и Ozon. Внизу карточки — одно общее предупреждение; в **Подробнее** — причины и время последней успешной проверки.
- Прежние цифры и их время сохранения не меняются при сбое. После успешного обновления пометка исчезает. Полный пустой ответ подтверждает **0 шт.**, неудачный запрос ноль не создаёт.
- Неожиданное исключение при запросе продаж WB тоже записывается по всему периоду. Незавершённая пагинация не принимается за полный ответ. Отмена самой задачи не создаёт ложных ошибок загрузки.
- Период с окончанием раньше начала отклоняется до обращения к API.

База остаётся на схеме 21. Единый блок, календарь, формулы и ограничения источников описаны в [обновлении 1.0.20](UPDATE_1_0_20_RU.md).

## Как сверить с кабинетом

1. Выберите один завершённый день, одинаковый в боте и кабинете. Проверьте выбранный магазин.
2. Нажмите **Обновить → Подробнее**. Сначала проверьте пропуски, предупреждения и время успешной загрузки каждого источника.
3. Сравнивайте отдельно заказы, выкупы и возвраты по дате соответствующего события. Начисления после удержаний сверяйте в **Начислениях Ozon/WB**, а не с суммой заказов.
4. После обновления отправьте свежий бэкап и цифры кабинета за этот день: количество и сумму по каждой строке, название раздела кабинета и выбранную дату.

Это исправление не подтверждает совпадение с реальным кабинетом: для такой проверки нужны свежие данные после ребилда.

Локальная проверка: **697 тестов прошли**. Компиляция, зависимости, аудит релиза и preflight на отдельной базе успешны; запросы к реальным кабинетам и Telegram в тестах не отправлялись.
