# Обновление 1.0.23: источники и предупреждения Ozon

## Что исправлено

| Сообщение или источник | Как работает теперь |
| --- | --- |
| Отчёт о выкупе товаров самим Ozon | Проверяется отдельно от продаж покупателям. Если полные списки FBO/FBS подтверждают отсутствие таких товаров, запрос не нужен и его старые ошибки не показываются |
| HTTP 429 | Это ограничение частоты запросов. Бот прекращает запросы к отдельному отчёту, учитывает серверный интервал ожидания и сохраняет прежние цены. Менять токен только из-за 429 не требуется |
| Дневная реализация: отказ Premium Plus | В строке «Выкуплено» видна причина отсутствия данных. Ручное обновление заново проверяет доступ; при отказе запрос не повторяется для каждого дня периода |
| Отмены Ozon | Пока дата отмены не получена, показан явный пропуск. Отмены среди заказов выбранного дня не выдаются за все отмены, произошедшие в этот день |

В проверенной резервной копии Ozon ответил на запрос дневной реализации: `Data is available only with a Premium plus subscription`. Код бота не может отменить требование подписки. Наличие API-токена само по себе не открывает этот отчёт. Заказы, клиентские возвраты и уже доступные начисления продолжают отображаться отдельно.

Для отдельного выкупа самим Ozon бот проверяет `is_marketplace_buyout` в каждом товаре обоих списков отправлений. Отсутствующий признак, неполный список или более поздняя ошибка загрузки не позволяют пропустить отчёт как ненужный.

## Что нажать после ребилда

1. Сохраните последнюю резервную копию вне хостинга.
2. Выполните ребилд существующего приложения из этого репозитория, ветка `main`. Сохраните прежние переменные, `DB_FILE` и постоянный каталог `/app/data`.
3. В боте откройте **Отчёты → Вчера**. Для другого дня нажмите **Выбрать дату**.
4. Нажмите **Обновить**, дождитесь завершения и откройте **Подробнее**. Для периода используйте **Обновить все отчёты** и кнопки выбора дней.
5. Если Ozon по-прежнему требует Premium Plus, строка «Выкуплено» останется без количества и суммы. Если доступ появится, снова нажмите **Обновить**: перезапуск не нужен.

Схема БД остаётся **21**. Цены покупателя, предельная цена API и начисления после удержаний остаются разными показателями. Неподтверждённые цены и отсутствующие события не превращаются в нули.

Сверка на резервной копии за 05.10.2026 проведена без изменения базы. Новые запросы к рабочему кабинету и отправка сообщений в Telegram в локальных проверках не выполнялись; их результат нужно проверить после ребилда.
